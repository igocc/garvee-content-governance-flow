# GARVEE Content Governance Flow

An interactive, single-page operating model for independent-site keyword governance and Shopify product-page AI delivery.

The page presents two views:

- Business operations: category selection, keyword calibration, content review, publishing, UGC/QA, and feedback.
- Product and systems: data readiness, contracts, rule engines, generation guardrails, release controls, and rollout gates.

Open `index.html` locally or view the published GitHub Pages site.
